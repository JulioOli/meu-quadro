# Mesa

Quadro pessoal de projetos e tarefas. Roda no navegador, sem instalação e sem servidor.

Inspirado no fluxo de uso de um quadro de projetos (kanban, lista, Gantt e tempo), numa versão enxuta para o dia a dia de uma pessoa só.

## Como abrir

Abra o arquivo `index.html` no navegador.

Não há build, dependência nem banco de dados. Os dados ficam no `localStorage` deste navegador.

## O que dá para fazer

- Criar projetos e tarefas soltas
- Ver o trabalho em **Kanban**, **Lista** e **Gantt**
- Definir início, prazo, estimativa, prioridade, tipo, tags e sprint
- Quebrar a tarefa em subtarefas e deixar comentários
- Lançar tempo na mão ou com um timer
- Renomear colunas e tipos em **Ajustes**
- Exportar e importar um backup JSON

## O que ficou de fora

BI, faturamento, vários responsáveis, SLA e anexos. O quadro é de uma pessoa.

## Backup

Em **Ajustes**, use **Exportar JSON** de vez em quando. Trocar de navegador ou limpar os dados do site apaga o quadro local. A importação restaura o arquivo exportado.
